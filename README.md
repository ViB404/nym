# 🎭 Nym

<div align="center">

<img src="https://i.imgur.com/6MmxPhm.png" alt="Nym Banner" width="100%">


**An anonymous social deduction game for Discord.**

Chat behind a random identity, outsmart your friends, and prove you're the best detective in the server.

## ✨ Features

* 🎭 Random aliases every round
* 💬 Anonymous messaging sent via webhooks
* 🗳️ Voting round after discussion round
* ⚡ Fully automated game flow (Need some fixes)
* 🎮 Designed for communities and friend groups

---

## 🚧 Beta

> **Nym is currently in Beta.**

The game is still under active development, so you may encounter bugs, unfinished mechanics, or breaking changes between updates.

Please report issues and feedback—they help improve the game.

---

## 📦 Installation

Install dependencies:

```bash
bun install
```

---

## 🚀 Running

Start the bot:

```bash
bun run index.ts
```
